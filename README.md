# Artistry — Digital Art Museum

Artistry is a modern, responsive digital art museum website that celebrates creativity and showcases artworks from different artistic movements. It provides an interactive platform for exploring artwork collections, discovering artists, and appreciating art through an elegant museum-inspired design.

## Features

- **Artwork Gallery:** Explore classical, impressionist, modern, and abstract artworks.
- **Search Artworks:** Search by artwork title, artist name, category, or year.
- **Category Filters:** Filter artworks by their artistic movement.
- **Artwork Details:** View artwork descriptions, artist names, creation years, and categories.
- **Favorites:** Save and remove favorite artworks with browser local storage.
- **Featured Artists:** Discover different artistic styles and creative perspectives.
- **Newsletter Form:** Interactive subscription form with confirmation feedback.
- **Responsive Design:** Works across desktop, tablet, and mobile devices.
- **Interactive Navigation:** Smooth scrolling, mobile menu, and artwork detail popups.

## Getting Started

### Prerequisites

- A modern web browser
- Visual Studio Code (recommended)
- Internet connection for external fonts, styles, and images

### Installation

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder:

   ```bash
   cd Artistry
   ```

3. Open `index.html` in your browser or use the Live Server extension in Visual Studio Code.

## How It Works

1. Browse the featured artwork collection.
2. Use category filters to explore different art movements.
3. Search for artworks using titles, artists, categories, or years.
4. Select an artwork to view its detailed information.
5. Add artworks to your favorites and revisit them later in the same browser.
